# CARE-VLA v1.2 reviewer release

The core asset packages the frozen benchmark data, VLM controls, and the Table 9 portable replay. Benchmark definitions and counts match the v1.2 manuscript.

- CARE-VLA_Reviewer_Core.zip includes the question-answer dataset, physical evidence, scoring code, and archived input-control responses.
- Validation includes corpus file and split checks, the fresh visual results by kitchen, and the report from the Windows replay.
- Table 9 covers 46 C2 rotary endpoints at three registered budgets. The portable verifier reruns the added witness and two unresolved cases with the original 4 mm criterion.

The authorship line identifies the dataset maintainer. The asset README documents the limits of the simulated task and upstream attribution.
